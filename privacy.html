Pee Daily 隐私政策

生效日期：2026-09-12

本隐私政策适用于 Pee Daily（“本应用”）。Pee Daily 是一款个人饮水与排尿日记工具。本政策说明我们收集、使用、存储和删除信息的方式。

我们处理的信息

  • 你主动记录的饮水、排尿、时间、数量、提醒设置和趋势数据。
  • 当你登录或启用云同步时，用于身份验证的 Apple/邮箱信息、Firebase 用户标识，以及用于同步上述记录的数据。
  • 订阅状态由 Apple 的 StoreKit 交易提供。本应用不会接触你的银行卡、完整支付信息或 Apple ID 密码。
  • 安装 Apple Watch 伴侣应用时，手机与手表之间可通过 Apple 的 WatchConnectivity 同步应用数据。

我们如何使用信息

我们使用这些信息提供日记、趋势、提醒、设备同步、Apple Watch 伴侣功能和订阅权益；处理故障、保护服务安全并回应支持或隐私请求。我们不会将健康日记用于广告画像或出售给数据经纪商。

存储与同步

未登录或未启用云同步时，记录保存在你的设备本地。当前版本使用应用沙盒中的本地 JSON 文件保存日记数据；本应用不会把本地记录上传到服务器，除非你使用需要云端同步的功能。

启用登录/云同步后，记录会发送到应用配置的 Firebase/Google Cloud 服务，用于在你的设备之间同步和恢复。第三方服务商仅按我们的指示提供身份验证、存储和基础设施服务。相关服务可能在你所在国家/地区以外处理数据；我们会依照适用法律采取必要的传输保护措施。

第三方服务与分享

本应用使用 Apple StoreKit 处理订阅交易，并可使用 Firebase/Google Cloud 提供身份验证和云同步；Apple、Firebase/Google Cloud 按其各自隐私政策处理相应技术数据。除你主动启用的云同步、Apple 订阅服务和 WatchConnectivity 外，我们不会把日记内容分享给广告商或数据经纪商。

本应用不出售你的健康习惯信息，不包含第三方商业广告追踪 SDK，也不读取 IDFA。

你的选择与数据权利

你可以在应用内关闭提醒、停止使用云同步、清除本地日记，并请求删除已上传的同步记录。在适用法律允许的范围内，你还可以请求访问、更正、删除、限制处理或导出你的个人信息，并撤回基于同意的处理。请通过邮箱或GitHub Issues联系我们，我们可能需要验证请求人的身份。

如需删除 Firebase 账户凭据本身，请通过上述邮箱提出账户删除请求。我们会在适用法律要求的期限内处理并回复。

保留期限

本地记录会保留至你在设备上清除或删除应用。云端同步记录会在账户启用期间保留，或直到你请求删除；删除后，必要的备份、审计或安全日志可能按照服务运行和法律义务保留合理期限。

安全

我们采取合理的应用沙盒、访问控制和传输安全措施，但任何电子存储或网络传输都不能保证绝对安全。

儿童与医疗用途

本应用不是面向儿童的服务，也不是医疗器械。趋势、提醒和评分仅供个人记录与一般信息参考，不构成诊断、治疗或紧急医疗建议。
