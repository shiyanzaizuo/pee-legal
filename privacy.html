Pee 隐私政策

生效日期：2026-09-12

Pee（“本应用”）是一款个人饮水与排尿日记工具。本政策说明本应用如何处理信息。

我们处理的信息

  • 你主动记录的饮水、排尿、时间、数量、提醒设置和趋势数据。
  • 当你登录或启用云同步时，用于身份验证的 Apple/邮箱信息、Firebase 用户标识，以及用于同步上述记录的数据。
  • 订阅状态由 Apple 的 StoreKit 交易提供。本应用不会接触你的银行卡或完整支付信息。
  • 安装 Apple Watch 伴侣应用时，手机与手表之间可通过 Apple Watch 的 WatchConnectivity 同步应用数据。

存储与同步

未登录或未启用云同步时，记录保存在你的设备本地。当前版本使用应用沙盒中的本地 JSON 文件保存日记数据；本应用不会把本地记录上传到服务器，除非你使用需要云端同步的功能。

启用登录/云同步后，记录会发送到应用配置的 Firebase/Google Cloud 服务，用于在你的设备之间同步和恢复。第三方服务商仅按我们的指示提供身份验证、存储和基础设施服务。

广告、追踪与分享

本应用不出售你的健康习惯信息，不包含第三方商业广告追踪 SDK，也不读取 IDFA。除你主动启用的云同步、Apple 订阅服务和 WatchConnectivity 外，我们不会把日记内容分享给广告商或数据经纪商。

你的选择

你可以在应用内关闭提醒、停止使用云同步，并清除本地日记。已上传的同步记录可以在应用内发起删除；如需删除 Firebase 账户凭据本身，请通过支持页面联系。

儿童与医疗用途

本应用不是面向儿童的服务，也不是医疗器械。趋势、提醒和评分仅供个人记录与一般信息参考，不构成诊断、治疗或紧急医疗建议。

安全与保留

我们采取合理的应用沙盒、访问控制和传输安全措施，但任何电子存储或网络传输都不能保证绝对安全。信息会在实现上述功能所需的期间保留；你删除本地或同步记录后，我们会按服务运行所需的合理期限处理备份和日志。

联系我们

请通过本网站对应 GitHub 仓库的 Issues 页面提交隐私问题、数据请求或删除请求。我们会在合理期限内回复。

政策变更

我们可能更新本政策，并在本页更新生效日期。

English summary: Pee is a personal hydration and urination diary. Data stays on-device unless you sign in or enable cloud sync. Cloud sync uses the configured Firebase/Google Cloud services. Apple handles subscription billing. We do not sell health data, use third-party ad tracking SDKs, or access IDFA. For privacy or deletion requests, use the repository Issues page linked from this site.
