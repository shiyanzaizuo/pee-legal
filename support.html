Pee 支持

这里提供 Pee 的使用帮助、订阅恢复和隐私请求入口。

恢复 Pee Pro

打开 Pee → 我的 → Pee Pro，点击“恢复已购项目”，并使用购买订阅时的同一 Apple ID。Apple 订阅状态由 App Store 管理。

云同步

未登录时，记录只保存在本机。登录并启用同步后，记录可在设备间同步。网络不可用时，记录仍可先保存在本机，稍后重试同步。

删除记录与账户请求

你可以在应用内清除本地记录并发起删除云端同步记录。若要请求删除 Firebase 账户凭据、提交隐私请求或报告安全问题，请在本仓库的 Issues 页面留言，并注明请求类型；不要在公开 Issue 中粘贴健康数据、密码或支付信息。

问题反馈

请在本页面所属 GitHub 仓库的 Issues 页面提交可复现步骤、系统版本和应用版本。请删除截图中的姓名、邮箱、健康数据和订单信息。

医疗问题

Pee 不是医疗服务。紧急症状请联系当地急救服务或医疗专业人员。
